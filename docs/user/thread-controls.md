# Thread controls

Thread keeps its controls beside the prompt. The model picker shows the selected model identifier, including its version. Choose it to change the model for your next message.

The lock control opens access settings. Its tooltip and accessible label identify the current access mode. Removing the text from the closed control does not change permissions.

Connection and working status appear above the composer when needed. During work, the status identifies the running thread model separately from your next-message selection. Approval requests and errors remain available in the conversation and composer.

The dedicated branding and title header and the empty-conversation placeholder are absent. Thread still uses the shared editor, conversation and sending behavior.
