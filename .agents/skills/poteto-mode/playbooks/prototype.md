# Prototype

The artifact is a cheap instrument for a decision, not a production feature.

1. State the uncertain decision, competing options and observation that would choose among them.
2. Gather references only where the design direction is open.
3. Build the smallest isolated sketch or probe outside production source, using existing dependencies and authorized resources.
4. Put competing visual variants behind a shared switcher or run behavioral alternatives against the same frozen input.
5. Observe the actual interaction or behavior and retain screenshots, output or timing that discriminate the options.
6. Recommend an option with its evidence, tradeoffs and scratch path, clearly naming what remains untested before a production build.

Use two or three genuinely competing variants when appropriate. Prefer experiment to asking a human for a fact that a run can determine. A pure prototype does not grant permission to install packages, open a browser, publish a site or implement the winner.
