# Autopilot-full

An independent queue can reach merged only under an explicit landing grant.

1. Freeze the independent queue, acceptance predicate per item, operator-owned gates, budgets and explicit commit, publication and merge grants.
2. Give each authorized owner a separate branch or worktree and a complete bounded lifecycle brief, with an early local decision trail.
3. Run independent owners concurrently only where files and state are isolated; dependent work waits for its prerequisite or reroutes to Autopilot-stack.
4. At each code-ready head, dispatch fresh independent verifiers for required checks, load-bearing behavior and relevant risk review.
5. Review every receipt yourself and consolidate findings for the owner; a changed patch gets a new verification round.
6. Let the authorized landing owner merge only the current verified patch with current checks and mergeability, then confirm the result and dispatch the next independent item.
7. Reconcile the queue after each result or wakeup and stop all owned work on explicit hold, completion, exhausted budget or a documented dead end.

The root owns the final verdict. A green check list, self-report or approving bot is not the verdict. Operator-named review gates stay with the operator. Missing landing authority reroutes to Autopilot-stack rather than inferring a merge grant. Use T3-native completion delivery and parent-owned PR watches, not Cursor cloud agents or bundled watchers.
