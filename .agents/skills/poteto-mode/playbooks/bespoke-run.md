# Bespoke run

Design one evidence-backed workflow for a large goal or a task the standard routes do not cover.

1. Restate the arbitrary goal and define checkable outputs, real constraints, scope, resource bounds and existing grants.
2. Ground the relevant domains and identify the smallest unknowns that can change the approach.
3. Resolve observable forks with isolated probes or competing sketches; ask for genuine missing product choices while progressing independent work.
4. Write a short custom sequence whose units each end in an independent observable check, naming one writer per shared target and the order of dependencies.
5. Execute the sequence within the grant, using the relevant standard playbooks for bounded subunits and a decision trail for longer work.
6. Review actual artifacts and acceptance evidence after each unit, revising the remaining sequence prospectively when evidence invalidates a premise.
7. Deliver the predicate result, verified outputs, unresolved gaps and a resumable next action if the stated budget or a real dead end prevents completion.

This is the figure-it-out role from the guide, implemented locally rather than depending on another pstack skill. A plan-only request ends after the sequence is delivered. Work that outlives one run and requires a standing frontier goes to Orchestrate.
