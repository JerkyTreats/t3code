# Eval

An actual behavior comparison needs an authorized resource budget and blinded candidates.

1. Freeze the variant, workload, success criteria, rubric, run count and spend or time limit before execution.
2. Prepare separate sanitized directories and ordinary-looking task prompts that reveal neither variant labels, other candidates nor the evaluator's rubric.
3. Run authorized candidates with the same task and controlled inputs, recording exact provider, model, revision and environment identities.
4. Have an independent judge inspect all outputs on one scale under neutral labels, preferably on a different available model family.
5. Grade claimed instruction-following from actual read and tool evidence, not a candidate's own statement.
6. Read every output yourself, compare the judge's findings, and report supported differences, confounds and promotion recommendation.

Use T3 delegation and bounded task status reads rather than Cursor transcript directories. Read only task-owned timelines. Static packaging or routing review is not an LLM eval. If delegation or independent judgment is unavailable, state that limitation instead of fabricating independence.
